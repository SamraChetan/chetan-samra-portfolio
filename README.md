# Chetan Samra — DevOps / Azure Cloud Portfolio

A responsive, static portfolio site built with HTML, CSS, and vanilla JavaScript. No build step or package installation is required.

## Before publishing

1. Open `index.html`.
2. Replace `YOUR_EMAIL@example.com` with your professional email address.
3. Replace the generic LinkedIn and GitHub links with your real profile URLs.
4. Review the project descriptions. They are written as representative capability summaries; keep only details that accurately reflect your experience and that you are allowed to share.
5. If you want, add a downloadable CV and link it from the hero or contact section.

## Preview locally

Double-click `index.html` or run a simple local server from this folder:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy to GitHub Pages

1. Create a new GitHub repository, for example `chetan-samra-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the Pages deployment to complete. Your site URL will be shown on the Pages settings screen.

If your repository is named `username.github.io`, GitHub Pages can serve it from the root domain. For a regular repository, the site URL normally includes the repository name.

## Notes

- The page uses Google Fonts; if unavailable, system fallbacks are used.
- All illustrations are built in CSS/SVG, so no image assets are required.
- This is a static site; the email button opens the visitor's email app and does not store form submissions.
